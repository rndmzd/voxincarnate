# Signal mouth-pose demo

Original vector artwork for Voxincarnate, provided under the project's MIT license.
Each transparent 400 by 400 image shares the same character; only the mouth changes.

The nine images use Rhubarb's A-H/X naming convention: A closed P/B/M; B teeth;
C medium open; D wide open; E rounded OH; F puckered OO; G F/V; H tongue L; X rest.
These are demonstration drawings, not evidence of phoneme-classification accuracy.

Rebuild the PNGs with the pinned Electron runtime:

```powershell
node node_modules/electron/cli.js scripts/generate-viseme-demo.cjs
```
